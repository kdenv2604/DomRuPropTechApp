# Безопасность

Приложение работает со служебными аккаунтами, дверями и видеопотоками, поэтому
публичная задача GitHub подходит не для каждого сообщения.

## Что нельзя публиковать

- логины и пароли;
- access token, refresh token, cookies и заголовки авторизации;
- действующие коды дверей;
- временные ссылки камер и кадры с людьми;
- полные ответы API с адресами и служебными идентификаторами.

Если проблема содержит такие данные, сначала удалите их из примера. До появления
отдельного закрытого канала безопасности сообщайте только обезличенное описание
и минимальные шаги воспроизведения.

## Защитные свойства приложения

- пароль используется только во время входа и не сохраняется;
- токены шифруются ключом Android Keystore;
- защищённые сессии исключены из резервного копирования;
- команда двери выполняется один раз и не имеет автоматического повтора;
- временная ссылка камеры хранится только в оперативной памяти;
- повреждённые сессии удаляются без попыток угадать или восстановить секреты.
