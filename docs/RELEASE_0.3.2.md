# lk.proptech.ru 0.3.2

Первая опубликованная демонстрационная версия нативного Android-клиента для
технического персонала.

## Главное

- несколько служебных логинов и один общий список доступных объектов;
- дерево «населённый пункт → улица → дом → подъезд»;
- открытие двери, получение действующего кода и живое видео домофона;
- запоминание последней раскрытой ветки;
- светлая и тёмная темы;
- адаптация адресов и кнопок к крупному системному шрифту;
- защищённые сессии Android Keystore без сохранения пароля;
- не больше трёх попыток безопасного чтения и ни одного автоматического повтора
  команды открытия двери.
