# lk.proptech.ru 0.3.3

Исправляющий выпуск для надёжного восстановления долгоживущей авторизации.

## Что исправлено

- пароль теперь сохраняется в зашифрованной записи Android Keystore;
- после смерти старых токенов приложение получает полностью новую сессию;
- безопасный запрос чтения после `401` повторяется с новым access-token;
- автоматический вход ограничен тремя попытками;
- параллельные запросы одного аккаунта не обновляют токен одновременно;
- удаление и замена пароля доступны только после окончательного отказа входа;
- для аккаунта из версии 0.3.2 пароль можно один раз сохранить без удаления.

Явно неверный пароль не отправляется три раза подряд: такой ответ окончательный,
поэтому повторы прекращаются сразу. Обычный сетевой сбой и `403` не помечают
логин сломанным и не открывают кнопку удаления.

## Обновление со старой версии

Версия 0.3.2 не сохраняла пароль. После установки 0.3.3 откройте список логинов
и один раз нажмите «Сохранить пароль». Новые логины сохраняют пароль сразу.
