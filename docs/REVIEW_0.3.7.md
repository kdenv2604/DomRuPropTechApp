# Проверка 0.3.7 — 10 октября 2026

Номер сборки: 11. APK подготовлена для установки; новый GitHub Release не публикуется.

Настройки перенесены в отдельную шестерёнку главного экрана. Панель сохранённых
логинов сохраняет своё назначение. В настройках добавлена «Удобная рука»:
по умолчанию правая; выбор сохраняется в display_preferences отдельно от аккаунтов.
В свёрнутом списке справа от кнопки открытия расположена подпись для правой руки;
для левой руки порядок зеркальный. В раскрытой карточке порядок ОТКРЫТЬ / КОД
также зеркальный. При крупном шрифте компактная кнопка выравнивается по выбранной
стороне, а действия карточки располагаются друг под другом.

Видеосоединение, API, хранение аккаунтов, красное оформление и режим только
предпросмотра не менялись. Звонков и полноэкранного режима в сервисной версии нет.

Проверено:
- testDebugUnitTest: 52 теста, 0 ошибок;
- lintDebug: 0 ошибок, 39 предупреждений;
- assembleDebug и assembleDebugAndroidTest: успешно;
- Android 14: HandednessUiTest (2 теста) и HandednessPreferencesTest (1 тест) — PASS;
- настоящие composables проверены без сети: шестерёнка → настройки, выбор обеих
  рук, порядок в строке и карточке, крупный шрифт 1.5, сохранение выбора после
  пересоздания preferences; настоящее пользовательское хранилище не используется.

Реальная камера и MIUI не проверялись: Poco в этом сеансе не подключён.
