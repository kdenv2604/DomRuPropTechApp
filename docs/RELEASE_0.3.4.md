# lk.proptech.ru 0.3.4

Интерфейсный выпуск с новой раскрывающейся карточкой подъезда.

## Что изменилось

- карточка подъезда теперь действительно меняет своё состояние вместо создания
  второй карточки ниже;
- `Под. 7` в раскрытом состоянии превращается в `Подъезд 7`;
- верхняя кнопка открытия плавно исчезает вправо;
- камера, открытие двери и получение кода находятся внутри одной карточки;
- при крупном системном шрифте нижние кнопки по-прежнему располагаются одна под
  другой и не закрывают текст;
- запоминание последнего раскрытого подъезда сохранено.
