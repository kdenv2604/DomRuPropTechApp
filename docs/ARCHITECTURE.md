# Архитектура приложения

Документ помогает быстро понять проект человеку, который впервые открыл
исходники.

## Общий путь данных

1. `DomruOidcClient` выполняет штатный вход через `id.dom.ru`.
2. `SecureSessionStore` шифрует пароль и выданные токены ключом Android Keystore.
3. `DomruSessionProvider` по очереди обновляет сессию одного аккаунта и при
   необходимости выполняет автоматический новый вход.
4. `ProptechApiClient` выполняет отдельные подтверждённые запросы портала.
5. `ProptechDomruRepository` загружает и кеширует каталог одного аккаунта;
   `RemoteCatalogBuilder` связывает полученные дома, подъезды и домофоны без сетевых запросов.
6. `CombinedAccessService` объединяет одинаковые объекты всех действующих
   аккаунтов.
7. `AppViewModel` хранит состояние экрана и не позволяет повторно нажать занятую
   кнопку.
8. Compose-экраны только показывают состояние и передают нажатия во ViewModel.

## Слои проекта

### `model`

Простые структуры данных без сети и Android-интерфейса: аккаунты, адреса,
состояния кнопок и выбранная ветка дерева.

### `data`

Авторизация, HTTP-запросы, шифрование сессий, разбор серверных адресов и
демонстрационный источник данных.

### `domain`

Правила приложения: объединение нескольких аккаунтов, поиск, выбор источника
доступа и ограничение повторов.

### `ui`

Jetpack Compose, состояние экрана, светлая и тёмная темы, камера и диалоги.

## Адресное дерево

Интерфейс использует три ступени. Дома улиц выбранного города берутся из
уже загруженного каталога; отдельного раскрытия улицы нет:

```text
Населённый пункт
└── Улица · Дом
    └── Подъезд
        ├── Камера
        ├── Открытие двери
        └── Код доступа
```

Одинаковые адреса разных аккаунтов показываются один раз. Внутри каждого общего
объекта остаётся список `AccessSource`, поэтому следующая загрузка знает, через
какие аккаунты можно обратиться к серверу.

## Важные ограничения

- Открытие двери всегда выполняется одной попыткой. Обновление адресов не снимает
  блокировку кнопки, пока эта команда не завершилась.
- Код и камера используют только безопасные запросы чтения.
- Камера останавливается при сворачивании приложения.
- Пароль и токены на диске всегда зашифрованы системным ключом Android; код двери
  и ссылка видеопотока на диск не записываются.
- Опасные действия над аккаунтом доступны только после подтверждённой потери
  сессии.

## Проверка привязки устройств

`RemoteCatalogBuilderTest` проверяет сборку на вымышленных ответах портала.
Неизвестные маршруты не совпадают по отсутствующим значениям; префикс маршрута
сравнивается по границе сегмента. Устройства, подходящие сразу к нескольким домам,
остаются в существующей группе «Другие объекты», пока привязка не станет однозначной.

`SecureSessionStoreTest` проверяет шифрованное хранение на Android в отдельном
файле настроек. Ошибка чтения не удаляет запись: временная недоступность Keystore
не должна приводить к потере пароля. Нечитаемая запись пропускается, а следующая
загрузка снова пытается её прочитать. Явное удаление аккаунта работает как раньше.


## Асинхронные операции

Фоновое обновление сессии сохраняет ответ только при совпадении исходной записи
с текущей. Удаление аккаунта проверяет то же условие. Поэтому старый запрос
не перезаписывает и не удаляет сессию, полученную новым явным входом.

После изменения аккаунтов незавершённая общая проверка отменяется. Проверки
оставшихся аккаунтов со статусом `CHECKING` запускаются заново; только что
проверенный вход остаётся `ACTIVE`.

Обновление каталога отменяет его старые загрузки. Ручной выбор адреса отдельно
отменяет поиск выбранного дома и восстановление сохранённой ветки, сохраняя
обычную загрузку домов. Запрос кода отменяется при смене адреса, переходе на
экран входа и сворачивании приложения; поздний ответ не возвращает окно кода.

`SessionConcurrencyTest` и `AutomaticLoginRetryTest` используют управляемые
ответы без сети. Android-тесты `AppViewModelAddressLoadingTest` и
`AppViewModelAccountCheckTest` проверяют поздние ответы, сохранение блокировки
двери и завершение проверок остальных аккаунтов после повторного входа.
