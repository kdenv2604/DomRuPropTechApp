## Автоматические проверки iOS

Полный прогон: **29 unit/integration-тестов и 4 UI-сценария — успешно**.
После уточнения обработки смены сети отдельно повторены тест контроллера камеры
и UI-сценарий камеры/возврата из фона — оба успешно.

| Проверки | Что подтверждено |
|---|---|
| `AddressTests` (7) | Разбор города/улицы/корпуса, пустые сегменты маршрута, поиск, разделение городов, объединение доступов, сохранение непривязанных дверей |
| `PortalTests` (9) | Формы с Unicode/спецсимволами, пагинация и specification header, одно открытие, подтверждение ответа, однократное восстановление GET после 401, код с ведущими нулями, URL и классификация ошибок |
| `SessionTests` (7) | Общий refresh для 20 одновременных чтений, независимые аккаунты, защита нового входа и удаления от старого refresh, запоздалый 401, прекращение повторов неверного пароля, ограниченный автовход |
| `RepositoryTests` (4) | Сбой аккаунта не скрывает другие двери; камера использует разрешённый источник той же двери; смена источника после ошибки; потерянный ответ открытия не вызывает команду через второй аккаунт |
| `KeychainTests` (1) | Запись и чтение настоящего Keychain из нового экземпляра хранилища; старая ревизия не перезаписывает новую |
| `CameraControllerTests` (1) | Свежая ссылка/новый плеер после фона и ошибки, даже при неизменном URL; запоздалая ошибка не выключает новый плеер; закрытая камера не возобновляется |
| `ServiceFlowTests` (3) | Дерево, реальные кадры FLV-fixture, код, возврат из фона, зеркальные кнопки, настройки отдельно от аккаунтов, поиск по сокращению |
| `AdaptiveLayoutTests` (1) | Прокрутка к камере и кнопкам, показ кода, фиксированная шапка |

`AdaptiveLayoutTests` также отдельно пройден на **iPhone SE с максимальным
шрифтом и тёмной темой**. Найденное при первом прогоне увеличение счётчика
аккаунтов в шапке исправлено; тест повторно пройден.

Плеер проверяется не только по состоянию `playing`: UI-тест ожидает фактически
показанные кадры. Тестовый FLV получен без перекодирования из прежнего
Android-fixture. Это локальный ролик, не запись настоящей двери.
