# lk.proptech.ru — Android-клиент для технического персонала

[![Проверка Android-проекта](https://github.com/kdenv2604/DomRuPropTechApp/actions/workflows/android.yml/badge.svg)](https://github.com/kdenv2604/DomRuPropTechApp/actions/workflows/android.yml)
[![Последняя версия](https://img.shields.io/github/v/release/kdenv2604/DomRuPropTechApp?label=версия)](https://github.com/kdenv2604/DomRuPropTechApp/releases/latest)

Нативный Android-клиент для сотрудников, которые обслуживают дома: электриков,
сантехников и других технических специалистов.

> **Важно:** это независимый неофициальный проект. Он не является продуктом
> Дом.ру, ЭР-Телеком или PropTech и не выдаёт себя за официальное приложение.
> Названия сервисов используются только для объяснения совместимости.

Текущая демонстрационная версия — **0.3.3**. Готовый APK находится в разделе
[«Релизы»](https://github.com/kdenv2604/DomRuPropTechApp/releases/latest).

## Что уже работает

- добавление нескольких служебных логинов внутри приложения;
- проверка состояния каждого логина с понятной отметкой действующего доступа;
- безопасное обновление пароля только после подтверждённой потери авторизации;
- штатный вход через `id.dom.ru` и восстановление аккаунтов после перезапуска;
- защищённое хранение паролей и отдельных серверных сессий средствами Android
  Keystore;
- автоматический новый вход после смерти старых токенов, не больше трёх попыток;
- один общий список населённых пунктов, улиц, домов и подъездов из всех
  действующих логинов;
- объединение одинаковых адресов без потери источников доступа;
- две команды у подъезда: открыть дверь и получить действующий код доступа;
- раскрытие только одной ветки адресов и одной камеры за раз;
- настоящий живой FLV-поток камеры в раскрытой карточке подъезда;
- восстановление последнего раскрытого населённого пункта, улицы, дома и
  подъезда после перезапуска;
- поиск по населённому пункту или сокращённому адресу, например `Адо 9`;
- перенос длинных названий по словам и отдельная раскладка кнопок при крупном
  системном шрифте;
- светлая и тёмная темы, переключатель находится только в настройках;
- безопасная политика повторов: чтение — не больше трёх попыток, открытие двери —
  всегда одна попытка;
- получение настоящих домов, подъездов и домофонов служебного портала;
- демо-данные для проверки интерфейса без настоящей учётной записи.

## Вход и хранение данных

Приложение отправляет введённые данные прямо на штатный сервер
`https://id.dom.ru/realms/lk` и использует публичный клиент `lk-frontend`.
На одно нажатие выполняется только одна попытка входа.

После успешного входа приложение сохраняет логин, пароль и выданные сервером
токены в одной зашифрованной записи. Ключ создаётся внутри Android Keystore и не
попадает в код приложения. Запись исключена из резервного копирования, а пароль
никогда не выводится в журнал. Он нужен только для автоматического получения
новой сессии, если старые токены больше не принимаются сервером.

Аккаунты, добавленные в версии 0.3.2 и раньше, не содержат пароля: старая версия
его действительно не записывала. После обновления для такого аккаунта нужно один
раз нажать «Сохранить пароль». Все аккаунты, добавленные начиная с 0.3.3, готовы
к автовходу сразу.

При нажатии «Выйти» приложение просит сервер завершить сессию и в любом случае
удаляет с телефона токены и сохранённый пароль.

Рабочий логин защищён от случайной смены пароля и удаления: соответствующие
кнопки для него скрыты. Если сервер подтвердил, что сессия закончилась, рядом с
удалением появляется «Новый пароль». Перед заменой приложение ещё раз проверяет
старую сессию. Если окончательно отвергнут и сохранённый пароль, приложение
разрешает заменить его или удалить учётку.

## Проверено на служебной учётной записи

Прямой вход, обновление токена, профиль, компания, дом, подъезды и домофоны
проверены на настоящей разрешённой сессии. Безопасный `GET` действующего кода тоже
проверен. Сам код в отчёты и журналы не записывался.

Видеометод вернул защищённую временную ссылку на `video/x-flv`, а живое изображение
успешно воспроизведено на настоящем Android-смартфоне. Ссылка хранится только в
оперативной памяти и забывается, как только приложение уходит в фон.

Команда открытия собрана точно по запросу веб-кабинета, но намеренно не запускалась
автоматической проверкой: это реальное действие с дверью. Её проверяет человек
обычным нажатием в приложении.

Служебный портал возвращает текущий код доступа, а не гарантированно одноразовый
код. Приложение только читает его и не создаёт, не заменяет и не продлевает.

## Как запустить демо

1. Собрать и установить вариант `debug`.
2. На первом экране нажать «Посмотреть интерфейс с демо-адресами».
3. Раскрыть улицу, дом и подъезд.

Демо не обращается к Дом.ру и не может открыть настоящую дверь.

## Установка готовой версии

1. Откройте [последний релиз](https://github.com/kdenv2604/DomRuPropTechApp/releases/latest).
2. Скачайте файл `lk.proptech.ru-debug-0.3.3.apk`.
3. Разрешите Android установку APK из выбранного браузера или файлового
   менеджера.
4. Установите приложение и добавьте служебный логин.

Сборка пока подписана отладочным ключом и предназначена для демонстрации и
полевой проверки. Для массового распространения нужен отдельный защищённый ключ
релизной подписи.

## Сборка

Минимальная версия системы — Android 8.0 (API 26), поэтому Android 10
поддерживается.

```bash
./gradlew testDebugUnitTest assembleDebug
```

Готовый APK появляется в `app/build/outputs/apk/debug/`.

## Где что лежит

- `model` — простые данные приложения;
- `domain` — объединение адресов, поиск и правила повторов;
- `data` — граница работы с сервером и безопасные демо-данные;
- `ui` — состояние экранов и интерфейс Jetpack Compose.

## Ограничения

- Для входа нужна действующая служебная учётная запись `lk.proptech.ru`.
- Команда открытия двери является реальным действием и не повторяется
  автоматически.
- Портал возвращает действующий служебный код, а не гарантированно одноразовый.
- Протокол служебного портала публично не документирован и может измениться.
